# Projeto-Individual
## Sistema de Gestão de Academia (Projeto Evolutivo Individual)

### 📝 Descrição do Projeto
Sistema desenvolvido em PHP para gerenciamento de alunos, matrículas, planos e treinos em uma academia.

### ⚙️ Funcionalidades Implementadas
- Cadastro e gestão de alunos e professores.
- Associação de planos às matrículas dos alunos.
- Lançamento e confirmação de pagamentos.
- Montagem e acompanhamento de treinos com exercícios.

### 🛠️ Conceitos de POO Aplicados
- **Encapsulamento:** Utilização de modificadores de acesso `private` e `protected` com métodos getters/setters.
- **Herança:** A classe `Pessoa` é herdada pelas classes `Aluno` e `Professor`.
- **Polimorfismo:** Sobrescrita do método `exibirDados()` nas subclasses.
- **Composição / Associação:** Relações entre `Matricula`, `Plano`, `Aluno`, `Treino` e `Exercicio`.
